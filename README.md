# monke-tools

This repo is initialized as a Bun project with Oxlint and Oxfmt wired in as the default linting and formatting tools.

## Quick start

```bash
bun install
bun run lint
bun run fmt:check
```

## Local install

```bash
bun run install:local
mt
```

Repo-specific tooling notes live in [docs/oxc-tooling.md](docs/oxc-tooling.md).
