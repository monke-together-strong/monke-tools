---
name: ape-it
description: Use when the user says "ape it".
---

1. If the request mentions council, run [council](../council/SKILL.md) on the
   approach and the questions it names, then carry the agreed approach forward.
2. Run `$implement` on the request.
3. Create the PR with `$pr`.
4. For a merge request, follow [merge-pr](../merge-pr/SKILL.md), which selects
   immediate or conditional merging. Otherwise shepherd it with `$shepherd-pr`.
