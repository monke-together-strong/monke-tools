---
name: ape-it
description: Use when the user says "ape it".
---

1. If the request mentions council, run [council](../council/SKILL.md) on the
   approach and the questions it names, then carry the agreed approach forward.
2. Follow [implement](../implement/SKILL.md) on the request.
3. Create each PR with `$pr`, including one a delegate opens in another repo.
4. Shepherd it with `$shepherd-pr`. If the request asks to merge, authorize
   merging once the PR is green.
