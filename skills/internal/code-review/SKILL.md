Before starting a review, read and follow both:

- [Matt Pocock's base review workflow](../../references/imported/code-review/MAIN.md)
- [the Team coding baseline](../../references/internal/CODING_STANDARDS.md)

Use the base workflow unchanged except for this Standards-axis authority order:

1. Repo coding standards
2. Team coding baseline
3. Matt's smell baseline

Apply every non-conflicting rule from all three sources. When rules conflict, the higher-authority source wins. Let the base workflow discover Repo coding standards; do not duplicate or narrow that discovery.
