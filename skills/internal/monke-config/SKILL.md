# Monke configuration

Author root `monke.yml` and its resource modules using the
[configuration reference](references/monke-yml.md).

For root PR or post-merge instructions, follow the linked contract:

- Author root `PR.md` using the [PR skill](../pr/SKILL.md#load-pr-requirements). Spawn seeds a gitignored `PR.md` from the Source checkout into a Session automatically.
- Author root `POST_MERGE.md` using the [post-merge skill](../post-merge/SKILL.md#load-the-contracts).
