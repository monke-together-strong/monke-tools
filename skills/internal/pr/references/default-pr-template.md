# Default PR template

Headings are optional for a small change. Include evidence and any required
visuals or post-merge checks per [Choose the evidence](../SKILL.md#choose-the-evidence).

```markdown
## Summary

<One or two sentences on the problem. Link the source issue.>

<The show-me view or consumer code blocks from Choose the explanation, when
Choose the explanation calls for them. Otherwise, a separate paragraph on the
resulting behavior.>

## Evidence

<Decisive behavior evidence, a meaningful benchmark, or a material verification limitation.>
```
