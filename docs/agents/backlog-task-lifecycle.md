# Backlog Task Lifecycle

1. Read the task, plus any attached references or documentation.
2. Set the task to `In Progress` and assign it to yourself when you start work.
3. Add the implementation plan to the task.
4. Implement the task and append notes as progress, decisions, and blockers happen.
5. Check acceptance criteria and DoD items as they are completed.
6. Add a reviewer-facing final summary.
7. Mark the task `Done` only after verification, checked acceptance criteria, checked DoD items, and a final summary are complete.
