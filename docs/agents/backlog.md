# Backlog.md Overview

Use Backlog.md through the CLI in this repository.

- Use `bunx backlog.md ...` for Backlog.md commands in this workspace.
- Do not assume plain `backlog ...` is safe on this machine.
- Use the CLI for task reads and writes.
- You may read task files directly for inspection when useful, but never write task files by hand.
- Prefer `--plain` when reading tasks or search results for agent consumption.
