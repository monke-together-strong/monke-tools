# Publish monke-tools and its shared Oxc presets publicly

After clearing the repository and its history for public redistribution, make monke-tools public under the MIT license for original work and publish its **Shared Oxc presets** as `@monke-together-strong/oxc-config` on public npm rather than GitHub Packages. Preserve applicable third-party licenses and remove imported material that lacks clear redistribution rights. The team controls the matching npm organization, and unauthenticated installation plus npm provenance are more valuable than keeping the source or package private.
